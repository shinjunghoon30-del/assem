## 1. 구조체(Structures)와 공용체(Unions)
### 구조체
- 논리적으로 연관된 변수(필드, Fields)들의 템플릿으로, 서로 다른 자료형의 필드를 가질 수 있으며 구조체 전체 또는 개별 필드로 접근
- 초기화 연산자에는 미초기화(?), 문자열 리터럴, 정수 상수/표현식, DUP를 이용한 배열 초기화가 가능
- 정렬(Alignment): 메모리 I/O 성능 향상을 위해 각 필드를 자료형에 맞는 경계에 정렬(ALIGN)하고, 구조체 변수 자체도 가장 큰 멤버의 경계에 맞추는 것이 좋
BYTE/SBYTE → 8-bit, WORD/SWORD → 16-bit, DWORD/SDWORD/REAL4 → 32-bit, QWORD/REAL8 → 64-bit 경계.
- 선언 및 참조: 구조체명 <초기값 목록> 또는 {}로 선언하며, 빈 꺾쇠(<>)는 기본값을 사용, 일부 필드만 지정할 때는 쉼표(,)로 위치를 맞춤
- TYPE, LENGTHOF, SIZEOF, OFFSET 연산자와 간접/인덱스 주소 지정(PTR 연산자 활용)을 통해 구조체, 멤버, 구조체 배열, 중첩 구조체(Rectangle 내 COORD, DrunkardWalk 내 path 배열 등)를 다룸

## 2. Unions (공용체)
공용체(Union)는 여러 데이터 필드가 동일한 메모리 공간을 공유하는 자료 구조
### 공용체의 특징
- 모든 필드가 같은 메모리 주소에서 시작
- 전체 크기는 가장 큰 필드의 크기를 기준으로 함
- 한 번에 하나의 초기화 값만 지정할 수 있음
- 필드를 사용할 때는 필드 이름을 지정해야 함
